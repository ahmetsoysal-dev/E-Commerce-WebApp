AspNetCore-ECommerce
ASP.NET Core MVC ve Entity Framework Core kullanılarak
öğrenme amaçlı geliştirilmiş, admin panelli ve dinamik yapıya sahip
bir e-ticaret web uygulamasıdır.

🚀 Özellikler
🔐 Rol bazlı yetkilendirme (Admin / Kullanıcı)
👤 Kullanıcı kayıt ve giriş sistemi
Admin ve kullanıcılar için farklı yönlendirmeler
🛠️ Admin Paneli
Ürün, kategori, marka ve sipariş yönetimi
⚙️ Site ayarları (Settings)
Footer iletişim bilgilerinin veritabanı üzerinden yönetilmesi
🔎 Filtreli ürün arama
🛒 Sepet ve Siparişlerim sayfası
⚡ AJAX ile sayfa yenilenmeden ürün listeleme
Scroll, buton ve sayfalama okları ile “load more”
🌐 Harici Web API entegrasyonları
Döviz kuru
Hava durumu
Nöbetçi eczaneler
Kültür-sanat / tiyatro etkinlikleri
🔄 Proje genelinde dinamik ve sürdürülebilir yapı

🧰 Kullanılan Teknolojiler
C#
ASP.NET Core MVC
Entity Framework Core
Microsoft SQL Server
Stored Procedure
View
HTML5, CSS3, Bootstrap
JavaScript, jQuery, AJAX
Web API

🗂️ Proje Yapısı
Controllers – İş mantığı ve yönlendirme
Models – Veri modelleri ve ViewModel yapıları
Views – Razor View katmanı
wwwroot – CSS, JS, görsel dosyaları
Data – DbContext ve veritabanı işlemleri
